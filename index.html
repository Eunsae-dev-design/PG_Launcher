QUESTIONS & ANSWERS

자주 묻는 질문

프로젝트와 계정 연동 방식에 대해 안내합니다.

PG Launcher를 지금 다운로드할 수 있나요?

아직 정식 다운로드를 제공하지 않습니다. Minecraft 인증과 모드팩 자동 패치, 게임 실행을 실제 환경에서 검증한 후 배포 여부를 안내할 예정입니다.

Microsoft 계정 로그인이 필요한가요?

PG Launcher는 Minecraft Java Edition의 정상적인 소유권과 Microsoft 계정 인증을 사용하는 것을 목표로 합니다. 비밀번호를 런처 화면에서 직접 수집하는 방식은 사용하지 않습니다. Minecraft Services API 사용 권한도 확인 중입니다.

여러 모드팩을 동시에 관리할 수 있나요?

가능하도록 개발 중입니다. Cobblemon과 Sunlit Valley를 별도 설치 경로에서 관리하여 한 모드팩의 변경이 다른 모드팩에 영향을 주지 않도록 설계하고 있습니다.

이 프로젝트는 Minecraft 공식 런처인가요?

아니요. PG Launcher는 개인 Minecraft 멀티플레이 커뮤니티를 위한 독립 개발 프로젝트입니다. Microsoft, Mojang, Minecraft 공식 제품과는 관련이 없습니다.

About PG Launcher — For application reviewers

PG Launcher is an independent, work-in-progress Windows desktop launcher for a private Minecraft Java Edition multiplayer community. Its planned features include Microsoft account sign-in, Minecraft ownership verification, profile and skin retrieval, separate modpack installation and updates (Cobblemon and Sunlit Valley), and direct multiplayer connection to eunsaesv.kro.kr. Minecraft Services API access approval is being requested. The launcher is not publicly released, and it does not collect Microsoft account passwords. PG Launcher is not affiliated with Microsoft or Mojang.
